this is my dart exercises load time check

This Dart program measures the time taken to complete a simulated processing task.

The program records the start time, runs a loop with 1,000,000 iterations, records the end time, and calculates the total processing time in milliseconds. How to Run Make sure Dart SDK is installed.

Open PowerShell or a terminal in the project directory:

cd C:\Users\n-cl-402-d24\Documents\dart_exercises

Run the program:

dart run


The start time, end time, and load time will be different each time the program is run.
